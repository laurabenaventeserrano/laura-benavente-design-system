The prism as a line: a 1px seven-stop rule, horizontal or vertical.

## Props
`orientation` (`horizontal` default, `vertical` uses `prism-v`), `short` for lines under about 120px (`prism-sm`), `neutral` for a `line-default` hairline where the prism would be too loud.

## Do
- Use it for the header's bottom rule, row separators and borders.
- Separate sections with space and a background change (`bg-page` to `bg-panel`), not with a line.

## Don't
- Never thicker than 1px. Never a fill, never behind text, never animated.
