The mono uppercase voice: kickers above headings and metadata lines.

- `kicker`: `label-kicker`, 12px, .2em tracking, `text-meta`.
- `meta`: `label-meta`, 11px, .16em tracking, `text-meta`.

## The consumer provides
The text (written in sentence case; the component uppercases it) and `as` for the element.

## Do
- Separate meta values with a middle dot: `Wolters Kluwer · 2025`.
- Keep it to a few words.

## Don't
- Never use mono for reading text, never in `lilac`, never in a prism colour.
